### 🔒 **一、Claude Code 权限模型概览**

Claude Code 采用**分级权限模型**，控制 AI Agent 对文件系统和终端命令的访问权限。

#### **权限层级**

| **层级** | **访问范围** | **默认状态** |
|----------|-------------|-------------|
| **文件读取（Read）** | 读取项目文件 | 允许 |
| **文件写入（Write）** | 创建和修改文件 | 允许（需确认） |
| **命令执行（Command）** | 在终端执行命令 | 允许（需确认） |
| **网络访问（Network）** | HTTP 请求 | 受限 |

---

### 📝 **二、权限控制方式**

#### **1. 文件系统权限**
- **读取**：Agent 可以自由读取项目目录下的文件
- **写入**：Agent 可以创建和修改文件，但重大修改会请求确认
- **删除**：删除操作需要明确确认

#### **2. 命令执行权限**
- Agent 可以通过 `!` 前缀执行终端命令
- 命令输出对 Agent 可见
- 如果不想让 Agent 看到命令输出，使用 `Ctrl+Z` 挂起后在终端手动执行

#### **3. Bash 命令模式控制**

| **命令方式** | **Agent 可见性** | **需确认** |
|-------------|-----------------|-----------|
| `! command` | Agent 可看到输出 | 是 |
| `Ctrl+Z` → 终端命令 → `fg` | Agent 完全不可见 | 否（手动执行） |

---

### 🛡️ **三、安全最佳实践**

| **实践** | **说明** |
|----------|---------|
| **审查所有写入操作** | Agent 创建/修改文件前，审查 diff |
| **敏感文件保护** | API Key、.env 等敏感文件不应被 Agent 读取 |
| **命令确认** | 安装依赖、删除文件等操作需人工确认 |
| **版本控制保护** | Commit 前审查所有变更 |
