以下是基于课程 "AI Coding for Real Engineers" (Cohort 004, Lessons 9-13) 中关于 Claude Code 键盘快捷键的系统性总结：

---

### 🎯 **Claude Code 核心快捷键**

#### **1. Ctrl+C（按两次）：完全退出 Claude Code**
- **作用**：彻底退出 Claude Code，返回普通终端
- **操作**：连续按两次 `Ctrl+C`
- **恢复方式**：退出后可用以下命令恢复会话：
  - `claude resume <UUID>`（通过会话 ID 恢复）
  - `claude --continue`（自动恢复最近会话）
- **注意事项**：
  - 会话状态会被保存，不会丢失
  - 恢复后可以继续之前的对话

---

#### **2. Ctrl+Z：挂起 Claude Code（放入后台）**
- **作用**：将 Claude Code 挂起并放入后台（标准 Unix 作业控制）
- **操作**：按一次 `Ctrl+Z`
- **执行终端命令**：挂起后可在终端运行任意命令
- **关键特性**：
  - 在终端执行的命令对 Claude **不可见**
  - 所有会话状态**完整保留**
- **恢复方式**：
  - 在终端中执行 `fg`（foreground）命令
  - Claude Code 将从后台恢复，状态完好无损
- **典型场景**：
  - 需要快速在终端执行某些操作，但不想让 Claude 看到这些操作
  - 需要临时做点事，但不想丢失当前的会话状态

---

#### **3. Ctrl+S：暂存当前提示（Stash）**
- **作用**：保存当前正在输入但尚未发送的内容
- **操作**：按 `Ctrl+S` 暂存当前输入框中的内容
- **使用场景**：
  - 正在输入一个长提示（long prompt），但突然发现需要先纠正 AI 的某个错误
  - 发完另一条消息后，暂存的内容**自动恢复**到输入框中
- **清空暂存**：
  - 按 `Ctrl+C` 丢弃暂存的内容
- **典型工作流**：
  1. 正在输入长提示给 AI
  2. 突然发现需要先纠正 AI 的某个错误
  3. 按 `Ctrl+S` 暂存当前输入
  4. 发送纠正消息
  5. 暂存的长提示自动恢复，继续发送

---

#### **4. fg（foreground）：恢复挂起的 Claude Code 会话**
- **作用**：将已被 `Ctrl+Z` 挂起到后台的 Claude Code 恢复到前台
- **操作**：在终端中输入 `fg` 并回车
- **关键特性**：
  - 所有会话状态**完整保留**
  - 恢复到挂起前的状态，可以继续之前的对话

---

### 🧭 **Bash 命令决策树**

在 Claude Code 中执行 bash 命令时，根据需求选择不同方式：

| **需求场景**                          | **操作方法**                              | **特点**                                 |
|---------------------------------------|------------------------------------------|------------------------------------------|
| **希望 Claude 看到命令输出**          | `!` 命令（bash 模式）                     | 输出对 Claude 可见                       |
| **短命令，等待结果**                  | 输入 `!` 命令后直接按 Enter，等待结果     | 简单直接                                 |
| **长命令（如启动开发服务器 dev server）** | `!` 命令 + `Ctrl+B` 放入后台            | 命令在后台运行，不阻塞当前交互            |
| **希望命令对 Claude 不可见**          | `Ctrl+Z` 挂起 → 执行命令 → `fg` 恢复     | 命令对 Claude 完全隐藏                    |
| **彻底退出 Claude Code**              | `Ctrl+C` 按两次                          | 完全退出，回到普通终端                    |

### 💡 **快捷键速查表**

| **快捷键**    | **作用**                              | **类比 / 说明**                           |
|---------------|---------------------------------------|-------------------------------------------|
| `Ctrl+C` × 2 | 完全退出 Claude Code                  | 类似普通程序的 `Ctrl+C`，但需按两次        |
| `Ctrl+Z`     | 挂起 Claude Code（放入后台）           | Unix 标准作业控制，`fg` 恢复               |
| `Ctrl+S`     | 暂存当前输入内容                      | 类似"草稿保存"，发完其他消息后自动恢复     |
| `fg`         | 将挂起的 Claude Code 恢复到前台        | Unix 标准命令                              |
| `Ctrl+B`     | 将 bash 中的长任务放入后台             | 搭配 `!` 命令使用                          |

### ⚠️ **使用注意事项**

1. **`Ctrl+Z` vs `Ctrl+C` 的选择**：
   - 只是想临时离开终端操作 → 用 `Ctrl+Z`，之后 `fg` 恢复
   - 想完全结束当前 Claude Code 会话 → 用 `Ctrl+C` × 2

2. **`Ctrl+S` 暂存的内容不会自动发送**：
   - 它只是保存输入框中的内容
   - 发送完其他消息后，暂存内容会恢复到输入框中
   - 仍需手动按 Enter 发送

3. **`!` 命令的可见性**：
   - 使用 `!` 前缀的命令，其输出会被 Claude 读取和分析
   - 如果不想让 Claude 看到某些操作，务必使用 `Ctrl+Z` 挂起

4. **会话恢复**：
   - `Ctrl+C` × 2 退出后，用 `claude resume <UUID>` 或 `claude --continue` 恢复
   - `Ctrl+Z` + `fg` 恢复时，状态始终完整保留
