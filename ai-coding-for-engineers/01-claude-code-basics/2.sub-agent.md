# Sub-Agent 模式 — Lesson 14

> 课程：AI Coding for Real Engineers (Cohort 004)
> 核心概念：子代理模式、任务委派、独立上下文、并行执行

---

### 🧩 **一、什么是 Sub-Agent（子代理）？**

Sub-Agent 模式是指在 Claude Code 中，将复杂任务拆分为多个子任务，每个子任务由**独立的 Claude Code 实例**在各自的上文窗口中执行。

#### **核心思想**
- 主会话（Main Session）负责协调和统筹
- 子会话（Sub-Agent Session）负责执行具体的独立子任务
- 每个子会话有独立的上下文窗口，不会互相污染

---

### 🔄 **二、Sub-Agent 的工作方式**

#### **基本流程**

```
Main Session（主会话）
    │
    ├── Sub-Agent A：任务 A（独立上下文）
    ├── Sub-Agent B：任务 B（独立上下文）
    └── Sub-Agent C：任务 C（独立上下文）

每个 Sub-Agent：
  - 独立的上下文窗口
  - 独立的会话历史
  - 完成后将结果交回主会话
```

#### **典型场景**

| **场景** | **说明** | **示例** |
|----------|---------|---------|
| **并行实现** | 多个互不依赖的功能同时开发 | 同时开发用户模块和设置模块 |
| **深度研究** | 需要独立探索某个技术问题 | 研究数据库 Schema 设计方案 |
| **独立测试** | 独立的测试环境 | 为某个模块编写完整测试套件 |

---

### 💡 **三、Sub-Agent vs. Session 切换**

| **维度** | **Sub-Agent 模式** | **手动 Session 切换** |
|----------|-------------------|---------------------|
| **协调方式** | 主会话自动协调 | 手动切换 |
| **上下文隔离** | 完全独立 | 完全独立 |
| **协调复杂度** | 低（由主会话管理） | 中（需要自己记住进度） |
| **并行能力** | 可并行 | 只能串行 |
| **适用场景** | 主会话需要同时推进多个子任务 | 单个任务专注执行 |
